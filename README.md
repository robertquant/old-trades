# 老行当消逝录

## 项目概述

**创作方向**：以散文笔触记录正在消失的中国传统手艺和老行当
**风格定位**：唐鲁孙式从容叙述——从一个人、一间铺、一条巷子写起，串联手艺、历史、人情，最终落在消逝的怅惘与时间的重量上
**创作频率**：每10分钟一篇（cron自动生成）

## 目录结构

```
old-trades/
├── README.md                 # 本文件
├── 已用题材索引.md            # 题材索引
└── essays/                   # 散文存放目录
    └── YYYY-MM-DD-主题.md
```

## 创作要求

- **篇幅**：1000-2000字
- **风格**：优美散文，文学性、画面感、烟火气
- **结构**：场景→人物→手艺→历史→消逝的怅然
- **核心**：不以手艺为限——真正写的是人、时间、正在消失的生活方式

## 创作流程

1. **选题**：从题材索引中选择未创作的题材
2. **查重**：读取索引确认未使用
3. **创作**：完成散文
4. **发布**：先发飞书，再保存文件
5. **更新索引**：在题材索引中标记已用
6. **提交**：Git commit & push
