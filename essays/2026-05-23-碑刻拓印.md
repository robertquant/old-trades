# 碑刻拓印

认识老姜，是在西安碑林第三展室。

那是前年秋天的事。我去看颜真卿的《多宝塔碑》，刚走到跟前，就看见一个瘦瘦小小的老头蹲在碑前，戴一副老花镜，手里拿着一个扑子，正往碑面上一下一下地扑墨。他的动作很轻，很慢，像在给一块石头做按摩。旁边站着一个年轻人，举着手机在拍，嘴里嘟囔着"爷爷你快点嘛"。老头头也不抬，说了一句："急什么，碑在这里站了一千多年，都不急。"

我就站在旁边看。看他先拿排笔蘸了清水，在碑面上薄薄地刷一层——不能多，多了墨会洇；不能少，少了纸贴不牢。然后把一张裁好的宣纸覆上去，宣纸是四川夹江产的，薄得像蝉翼，湿了水就变得透明，能隐隐看见底下石刻的笔画。他用一把棕刷，从中间往四周轻轻地刷，把纸与碑面之间的气泡一个一个地赶出去。那动作像在抚摸一个婴儿的脸——力道重了，纸就破了；轻了，纸就贴不住。老姜的手很稳，刷子在他手里像长出来的。

等纸半干，他换了扑子。扑子是丝绵裹的，外面包一层细绸，蘸了上好的油烟墨，先在旁边一张废纸上试了试浓淡，然后才开始往碑面上扑。扑墨是关键——力道要匀，每一扑下去，墨色要一致；方向要对，顺着字的笔画来，不能横着来，会模糊了字的筋骨。老姜一边扑一边跟我说："拓碑这件事，说白了就是把石头上的字搬到纸上。但你怎么搬，就看出人的高低了。墨重了，字就显得肥，没了神气；墨轻了，字就显得瘦，没了骨力。要恰到好处，让石头里的字活到纸上来，这才是本事。"

我问老姜干这行多少年了。他说，十七岁进的陕西省博物馆，跟在周老师傅后面学拓碑，到今年刚好六十年。六十年里，他拓过《曹全碑》《张迁碑》《九成宫》，拓过大小雁塔里的佛像题记，拓过乾陵无字碑旁边的述圣纪碑。他说他最难忘的，是一九七三年去药王山拓《姚伯多造像记》——那是一块北魏的碑，在荒山野岭里站了一千五百年，碑面上的字被风雨剥蚀得几乎看不清了。他和周师傅在山上住了七天，一张一张地拓，把那些快要消失的字抢救到纸上。"拓到最后一行的最后一个字的时候，"老姜说，"我忽然哭了。那个字只剩下小半个笔画，再过十年，也许就什么都没有了。我把它拓下来，好像给一个临死的人拍了最后一张照片。"

老姜说，拓碑这门手艺，和别的老行当不一样的，是它的"对象"。铁匠打铁，银匠敲银，木匠做木头——这些材料不会说话。但碑会说话。每一块碑都是一段历史，你往上面扑墨的时候，手底下是颜真卿的筋骨、欧阳询的锋棱、柳公权的骨架。一千多年前的人握笔写下的笔画，一千多年后的人用手去摸、用墨去拓——时间在这块石头上，忽然就不是一条线了，而是一个圈。

我问老姜收徒弟没有。他指了指旁边那个还在拍视频的年轻人："我孙子，学了三年了，还学不会。不是手笨，是心不定。他总想着快点搞完，好发到网上去。这门手艺，快不了的。"他又指了指手里的扑子，"你想想，一块碑少则几百字，多则一两千字，每一笔都要这么一下一下地扑。快的半天拓一张，慢的两三天拓一张。你心里要是没有这块碑，墨就进不到纸里去，永远只能拓出一张黑乎乎的纸片。"

老姜说，现在拓碑的人越来越少了。机器可以扫描，电脑可以建模，谁还愿意蹲在碑前，花一整天时间去拓一张拓片？更何况，很多碑已经不让拓了——为了保护文物。碑林里的重要碑刻现在都封起来了，隔着玻璃才能看见。"这是好事，"老姜说，"碑本来就应该在石头上，搬来搬去反而伤了它。但是——"他顿了顿，叹了口气，"碑上的字，你不去拓，它就隔着玻璃站在那儿，像一个被人参观的老人，谁也不去听它说话。再过一千年，字还在，但是没人读得懂了。没人读得懂的字，跟没有字又有什么区别呢？"

那天老姜拓的是颜真卿四十四岁时写的《多宝塔碑》。我看了整整一个下午。看着他一下一下地扑墨，看着碑上的字一点一点地在纸上浮现出来——先是横，再是竖，然后是撇、捺、钩、挑。每一个笔画都清清楚楚，每一个字都像刚刚从石头里醒过来。等到整张拓片揭下来的那一刻——纸从碑面上慢慢地掀起来，发出轻微的撕裂声——我忽然明白了老姜说的那句话。

字活了。

老姜把那天的拓片送给了我。我裱好，挂在书房里。有时候夜深了，灯下看着那些墨色如新的字，想着那是一千二百五十年前一个叫颜真卿的人写的，六十年拓龄的老姜把它从石头上"请"到纸上来，现在它又来到了我的墙上——时间在这张纸上，真的成了一个圈。

前几天我又去碑林，第三展室还在，碑也在。老姜不在。问门口的工作人员，说姜老师退休了，回老家了。我没有再问下去。

碑还在。字还在。但是把字从石头上叫醒的那个人，已经不在了。那些碑，又要沉回沉默里去，在玻璃后面站着，等下一个还没出生的人来听。
